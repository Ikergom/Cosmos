# :gear: COSMOS :gear:

## Aplicaciones a descargar.
- `1`: Descargamos el Visual Studio 2022.-
- `2`: Tambien tendremos que instalar l'SDK de .NET 6.0..-
- `3`: Tambien tenemos que tener cuenta en GitHub. -
- `4`: Mas adelante tambien necesitaremos el VmWare. -

## Instalacion.
  ### Visual Studio 22
- `1` : Lo rpimero que tenemos que hacer es una vez tenemos el instalador del Visual Studio 2022 la version Cmmunity.
- `1` : https://visualstudio.microsoft.com/es/vs/.
- `2` : Ahora tenemos que marcar las opciones de **Desarollo de escritorio .NET** y tabien la de **Desarollo de extensiones de Visual Studio**.
- `3` :A parte de eso tenemos que ir a **Componentes indibiduales** que esta en la parte superior de la pantalla.
- `4` :Una vez dentro tenemos que seleccionar la opcion de **.NET 6.0 Runtime** y le damos a instalar.

  ### SDK NET6.0
- `1` :De mientras lo que tenemos que hacer es instalarnos el SDK .NET 6.0
- `1.` :lINK : https://dotnet.microsoft.com/en-us/download/dotnet/6.0

  ### GitHub
- `1` :Ahora entramos en GitHub y iniciamos sesion.
- `2` :Una vez dentro  tenemos que ir al GitHub oficial de CosmosOs y nos descargamos el zip.
- `3` :Descomprimimos el zip y dentro le tenemos que dar a **install-VS2022**.

  ### VmWare
- `1` :Instalamos el VmWare.
- `2` : :warning: Si nos da error lo que tenemos que hacer es entrar al cmd como administrador :warning: .
- `3` :Dentro del cmd temeos que poner **net localgroup /add "Users"**.
- `4` :Si todavia no te deja tendras que probar con las siguientes dos comandas.
- `5` :Comando **net localgroup /add "Authenticated "Users"** y **net localgroup /add "Administrators"**

## Visual Studio 22

- `1` :Una vez ya tenemos todo entramos en el Visual Studio 2022 y le damos a **Crear proyecto**
- `2` :Tenemos que darle a la opcion de **Cosmos Kernel #C**
- `3` :Una vez ya estamos dentro lo que tenemos que hacer es activar el VmWare
